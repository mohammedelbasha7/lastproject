# Project Summary
Leroy Design is an Israeli online furniture store specializing in high-quality European-imported beds and mattresses. The project aims to create a luxurious and user-friendly e-commerce platform that allows customers to effortlessly browse, select, and purchase furniture. The platform features a clean aesthetic and responsive layout to enhance the shopping experience, now including multiple payment options for Israeli customers, including the recently integrated Max payment method. The checkout process has been updated to allow guest purchases without requiring a login. Recent enhancements include improved category navigation and dedicated category pages for a better user experience.

# Project Module Description
The project consists of a frontend and backend system:
- **Frontend**: Developed using React, TypeScript, and Tailwind CSS, it provides a seamless user experience with sections for product categories, featured items, testimonials, and a contact form. A shopping cart and payment integration facilitate purchases, with a focus on reliable checkout processes. Recent updates have improved the RTL layout for better mobile usability and added dedicated category pages for product filtering.
- **Backend**: Built with FastAPI and PostgreSQL, it manages products, categories, testimonials, and payment processing, featuring a full CRUD API and a secure payment system via Stripe, now supporting guest checkouts. Recent changes have improved error handling related to payment processing.

# File Description Inventory
- **app/backend/**: Contains backend logic, including models, routes, and services for handling requests.
- **app/frontend/**: Contains frontend code, including components, pages, and styles for the user interface and admin panel.
- **app/backend/requirements.txt**: Lists Python dependencies for the backend.
- **app/frontend/package.json**: Lists JavaScript dependencies for the frontend.
- **app/backend/routers/payments.py**: Handles payment processing and order management, now supports guest checkout and improved error handling.
- **app/frontend/src/contexts/CartContext.tsx**: Manages cart state and functionality.
- **app/frontend/src/pages/Cart.tsx**: Displays the shopping cart and checkout options, updated to remove login requirement for checkout and improve RTL layout.
- **app/frontend/src/pages/PaymentSuccess.tsx**: Confirms payment status and displays a success message.
- **app/frontend/src/pages/CategoryPage.tsx**: Displays products filtered by category.
- **app/frontend/src/components/CategoryGrid.tsx**: Displays category buttons linking to their respective category pages.
- **app/frontend/src/components/Header.tsx**: Navigation header including links to categories and contact information.
- **app/frontend/src/components/ProductSection.tsx**: Displays products based on category or featured items.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, Vite
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic for migrations
- **Database**: PostgreSQL
- **Payment**: Stripe for payment processing, now including Max (formerly Leumi Card)
- **Deployment**: Docker for containerization

# Usage
1. **Install Dependencies**:
   - For the backend, navigate to `app/backend/` and run:
     ```
     pip install -r requirements.txt
     ```
   - For the frontend, navigate to `app/frontend/` and run:
     ```
     pnpm install
     ```

2. **Build and Run**:
   - Backend: 
     ```
     python app/backend/main.py
     ```
   - Frontend:
     ```
     pnpm run build
     ```
